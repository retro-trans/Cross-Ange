# Whole-PKG route withdrawn

The user returned to installed-file CPK patching because the encrypted whole-PKG delta was approximately 945 MB. The whole-PKG profile and ZIP have been removed from the release; local tools 0.5.12–0.5.14 builds are withdrawn.

Install the original Japanese PCSG00597 game with its matching `work.bin`/`.rif`, close Vita3K, then patch its installed `cpk/Ange.cpk` with the approximately 5.35 MB delta. See [current instructions](patch-installation.md). The license is required for base-game installation, not CPK patching.

Earlier PKG verification records remain historical evidence. No custom PKG is part of the current player flow.
