# Historical release instructions

These component-patching instructions are superseded. The current public release uses a whole-PKG delta; follow the [current installation instructions](../patch-installation.md). Its old CPK/component downloads have been retired.

English fan translation of **CROSS ANGE Rondo of Angel and Dragon tr.** for PS Vita (**PCSG00597**).

### Apply

**Recommended:** Use the latest [Retro Trans](https://github.com/retro-trans/retro-trans-tools/releases/latest) app. Copy your own original decrypted `cpk/Ange.cpk` and `sce_sys/param.sfo` into one working folder. Click **Refresh catalog**, open **Automatic**, choose that folder with **Folder…**, select **Cross Ange English components (PCSG00597)** and **0.1.12** or **Latest**, then choose a new output folder. The app downloads both patches and verifies both results. If the catalog has not picked up the release yet, use manual patching.

Download `Cross-Ange-English-0.1.12-extras.zip` separately for the new credits page and font license. See [installation instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/patch-installation.md) to place all files in the existing game folder. This is a decrypted-file workflow; the app's **Vita rePatch — Z3** feature does not support this game.

**Manual patching:** Use Retro Trans **Apply xdelta**, [Delta Patcher](https://github.com/marco-calautti/DeltaPatcher), or [xdelta3](https://github.com/jmacd/xdelta):

| Original source component | Patch | Patched output placement |
| --- | --- | --- |
| `cpk/Ange.cpk` | `Cross-Ange-English-0.1.12-Ange.xdelta` | `cpk/Ange.cpk` |
| `sce_sys/param.sfo` | `Cross-Ange-English-0.1.12-param.xdelta` | `sce_sys/param.sfo` |

```text
xdelta3 -d -s original/Ange.cpk Cross-Ange-English-0.1.12-Ange.xdelta english/Ange.cpk
xdelta3 -d -s original/param.sfo Cross-Ange-English-0.1.12-param.xdelta english/param.sfo
```

Create the `english` directory first. Only the exact original files below are supported. Prior local English builds are not upgrade inputs. Close Vita3K, preserve the original app and saves, copy the patched components to their original paths, and add the extras' `sce_sys/manual/025.png` and `sce_sys/font-license.txt`. Keep all original manual pages and other game files. Restart and check **v0.1.12** at the title screen.

### Release status

**This is an early test release. Further proofreading and full in-game playtesting are needed.** All 17,151 identified structured targets are inserted, with 106 of the 130 drafted raster source regions rendered into 114 text rectangles. These are resource counts, not a whole-game completion percentage.

Twenty translation/font/UI/texture/branding checks passed. Local Vita3K installation verified 48 files and independently read back all 483 replacement archive members, 46,048 native font records and 13 compact UI fields. Both release patches were decoded and compared against complete target hashes by the Retro Trans release builder. Retro Trans's actual grouped Automatic implementation also recognized both originals, applied both local patch assets and verified both complete outputs. `RETRO-TRANS-VALIDATION.json` records that compatibility check. This proves file contents and patch reproducibility, not every scene's runtime appearance.

New tutorial and battle-result layouts still need live confirmation. A duplicate Naomi eye-animation tile remains unresolved. The other 24 raster reading regions, original manual prose and movie logos remain pending. There are 139 provisional equipment-name proposals. Some long dialogue uses native 80% size. Physical-Vita runtime and the appended manual page's console installation are unverified.

**Restart the game after replacing files.** Keep normal saves and existing licenses; no game license or executable is included.

### What's included

English scenario dialogue and choices, speaker labels, menus and help, battle-partner/navigation captions, gallery fields and system titles. All 15 chapter/prologue headings appear in both graphic variants. All ten identified tutorial pictures include English labels and embedded samples. The build uses **GenEi LateGo v2 Medium** with native proportional advances, pixel-width wrapping, a title-screen version footer and an appended Retro Trans manual credits page.

### How it was translated

This is a **machine translation**, drafted with large language models and then reviewed and edited using adjoining scene context and a researched glossary. English catalogs retain source IDs, review notes and uncertainty flags. Human proofreading and playtesting are welcome.
