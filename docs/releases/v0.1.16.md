English fan translation of **CROSS ANGE Rondo of Angel and Dragon tr.** for PS Vita (**PCSG00597 v01.00**, Japanese release).

### Apply

**Recommended — [Retro Trans 0.5.18](https://github.com/retro-trans/retro-trans-tools/releases/tag/v0.5.18), Automatic tab:** Select your original Japanese PKG, its matching **work.bin / compatible NoNpDrm .rif**, and a new output filename. Click **Patch** to download about **5.4 MB** of translation patches and rebuild the English PKG locally. Allow **6 GB free**; the tools' Vita3K runtime downloads separately on first use.

Use Tools 0.5.18 for Automatic discovery; 0.5.16 can reject another game's larger profile before patching. Its local ZIP route remains compatible.

Install the output in Vita3K with the **same matching license** and check **v0.1.16** in the title footer. Licenses are never bundled or downloaded. The source PKG is **925,548,400 bytes**, SHA-256 `962498429645bf92d0171280b075629ff6dc8100f365ce43805d2cd3e897ebcb`.

**Manual installed-file patching:** Install the original licensed game first, close Vita3K, and back up its files. Use Retro Trans's **Apply xdelta**, DeltaPatcher or xdelta3:

| Original installed file | Patch |
| --- | --- |
| `cpk/Ange.cpk` | `Cross-Ange-English-0.1.16-Ange.xdelta` |
| `sce_sys/param.sfo` | `Cross-Ange-English-0.1.16-param.xdelta` |

```text
xdelta3 -d -s Ange.cpk Cross-Ange-English-0.1.16-Ange.xdelta Ange-English.cpk
xdelta3 -d -s param.sfo Cross-Ange-English-0.1.16-param.xdelta param-English.sfo
```

Replace the installed files with the verified outputs, then copy the credits/font files from `Cross-Ange-English-0.1.16-extras.zip`. Start from original files, including when upgrading an older translation. Exact component identities are in `BUILD-MANIFEST.json`; [full instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/patch-installation.md) include the hashes.

**Hardware Vita:** Use the separate [rePatch route](https://github.com/retro-trans/Cross-Ange/blob/main/docs/repatch-installation.md). Physical-Vita gameplay remains unverified.

### What's included

- English drafts for **17,151 identified text targets**, **15 chapter/prologue headings** and **10 tutorial pictures**.
- Briefing text wrapping, consistent **Light of Mana / Mana user** wording and clearer HUD lettering.
- Wider timed-conversation bubbles; **211 comments/reactions checked, 161 rewrapped**.
- GenEi LateGo v2 Medium, proportional spacing, versioned title footer and credits on manual page 25.
- Small PKG-rebuild patches, manual component deltas, credits/font attribution and hardware rePatch patches.

### Release status

**Further proofreading and full playtesting are needed.** Both deltas roundtrip exactly; the rebuilt PKG passed an isolated native Vita3K installation with all **48 file hashes** verified. All **27 translation/font/layout checks** pass.

Published Tools **0.5.18** also downloaded this release through Automatic with an empty cache and no GitHub sign-in or local patch, reproducing the exact verified PKG and all 48 installed files.

For emulator HUD corruption, use the separate [experimental Vita3K build](https://github.com/retro-trans/Vita3K/releases/tag/v0.2.1-cross-ange-hud.1). Its compiled translator passes all 256 native reference checks; the equivalent cached correction improved Vulkan rendering. The rebuilt emulator still needs battle testing. This correction is separate from the game patches.

Known issues include the duplicate Naomi eye-animation tile, coloring preview requiring a hangar re-entry, remaining raster/manual/movie text, provisional equipment names and smaller text on some long dialogue. New bubble layouts, all HUD states and physical hardware remain unverified. Counts describe identified resources, not whole-game completion.

### How it was translated

Drafted with large language models, then reviewed and edited using scene context and a researched glossary. Human proofreading and playtesting are welcome.
