English fan translation of **CROSS ANGE Rondo of Angel and Dragon tr.** for PS Vita (**PCSG00597 v01.00**, Japanese release).

Version **v0.1.16** brings cumulative briefing, terminology, HUD lettering and timed-dialogue layout repairs.

### Apply

**The easiest way:** Download [Retro Trans 0.5.18](https://github.com/retro-trans/retro-trans-tools/releases/tag/v0.5.18). In **Automatic**, select your original Japanese PKG, its matching **work.bin / compatible NoNpDrm .rif**, and a new output filename. Click **Patch** to download about **5.4 MB** of translation patches and rebuild the English PKG locally. Allow **6 GB free**; the Vita3K runtime downloads separately on first use.

Use **0.5.18** for Automatic discovery; 0.5.16 can reject another game's larger profile before patching. Its local ZIP route remains compatible.

Install the output in Vita3K with the **same matching license** and check **v0.1.16** in the title footer. Licenses are never bundled or downloaded. The source PKG is **925,548,400 bytes**, SHA-256 `962498429645bf92d0171280b075629ff6dc8100f365ce43805d2cd3e897ebcb`.

**Other ways:** Install the original licensed game first, close Vita3K, and back up its files. Apply the component patches with Retro Trans's **Apply xdelta** or [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher):

| Original installed file | Patch |
| --- | --- |
| `cpk/Ange.cpk` | `Cross-Ange-English-0.1.16-Ange.xdelta` |
| `sce_sys/param.sfo` | `Cross-Ange-English-0.1.16-param.xdelta` |

**Command line:** Use [xdelta3](https://github.com/jmacd/xdelta):

```text
xdelta3 -d -s Ange.cpk Cross-Ange-English-0.1.16-Ange.xdelta Ange-English.cpk
xdelta3 -d -s param.sfo Cross-Ange-English-0.1.16-param.xdelta param-English.sfo
```

Replace the installed files with the verified outputs, then copy the credits/font files from `Cross-Ange-English-0.1.16-extras.zip`. **Start from original files, including when upgrading an older translation.** Exact component identities are in `BUILD-MANIFEST.json`; [full instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/patch-installation.md) include the hashes. Check the source if a checksum fails; keep source verification enabled.

**Hardware Vita:** Use the separate [rePatch route](https://github.com/retro-trans/Cross-Ange/blob/main/docs/repatch-installation.md). Physical-Vita gameplay remains unverified.

### What changed since v0.1.13

- **Briefing text fits its panels.** Audited 65 mission descriptions and reflowed 42, retaining complete wording and warning colors.
- **Mana terminology is consistent.** Uses **Light of Mana** for the power and **Mana user** for a person in the reviewed dialogue.
- **HUD lettering is clearer.** Improves small speed, timer and Freeze Bullet labels and counter digits. HUD placement corruption requires the separate emulator correction below.
- **Timed dialogue has more room.** Widens conversation bubbles to about 336 pixels; checks all **211 comments/reactions** and rewraps **161** using native font widths.
- **Earlier translation work is retained.** Includes the GenEi proportional font, translated headings/tutorials and version-matched title footer and credits.

Both component deltas reproduce their exact verified outputs. All **27 translation/font/layout checks** pass, and native Vita3K installation verifies all **48 game file hashes**. Original executable and unrelated archive content are preserved.

### Testing and compatibility

**Further proofreading and full playtesting are needed.** New bubble layouts, all HUD states and physical-Vita gameplay remain unverified. Known issues include the duplicate Naomi eye-animation tile, coloring preview requiring hangar re-entry, remaining raster/manual/movie text, provisional equipment names and smaller text on some long dialogue.

Published Tools **0.5.18** also downloaded this release through Automatic with an empty cache and no GitHub sign-in or local patch, reproducing the exact verified PKG and all 48 installed files.

For emulator HUD corruption, use the separate [experimental Vita3K build](https://github.com/retro-trans/Vita3K/releases/tag/v0.2.1-cross-ange-hud.1). Its compiled translator passes all 256 native reference checks; the equivalent cached correction improved Vulkan rendering. The rebuilt emulator still needs battle testing. This correction is separate from the game patches.

Fully stop and relaunch the game after patching, load an in-game save and check **v0.1.16** in the title footer. This release contains the verified tagged build; later source edits are not automatically included.

### What's included

- **Original-PKG Automatic:** `VITA-PKG.json` and `Cross-Ange-English-0.1.16-Vita-PKG-patches.zip` for local licensed rebuilding.
- **Manual installed-file patches:** the two `.xdelta` files, extras ZIP, build manifest, checksums and validation records.
- **Hardware rePatch:** `VITA-REPATCH.json` and `Cross-Ange-English-0.1.16-Vita-rePatch-patches.zip` for the documented hardware route.
- English drafts for **17,151 identified text targets**, **15 chapter/prologue headings** and **10 tutorial pictures**, plus GenEi LateGo v2 Medium and credits on manual page 25. Counts describe identified resources, not whole-game completion.

The game patches do not include a complete game, a license or the separate experimental emulator.

### How it was translated

This is a **machine translation**, drafted with large language models, then reviewed and edited using scene context and a researched glossary. Further human proofreading and playtesting are welcome.
