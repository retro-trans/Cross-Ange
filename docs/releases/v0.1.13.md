English fan translation of **CROSS ANGE Rondo of Angel and Dragon tr.** for PS Vita (**PCSG00597**, Japanese release).

### Apply

**Installation requirement:** you must have your own `work.bin` for **Cross Ange PCSG00597** (or its matching compatible `.rif`). A license from another game will not work. It is not included in the patch and is never downloaded by the tools. Whole-PKG patching does not read it; supply it when installing the result in Vita3K.

**Automatic:** use your local **Retro Trans 0.5.14** app. Open **Automatic**, browse to your original Japanese `.pkg`, choose a new **Translated PKG** filename and click **Patch**. The matching whole-PKG translation ZIP downloads automatically. **Patching needs no `work.bin` or `.rif`.** Install the result through Vita3K's **File → Install .pkg**, supplying your matching local license when Vita3K asks, then restart and check **v0.1.13** on the title screen.

The game repository and release are private again. Automatic downloads require an existing GitHub CLI sign-in with repository access; use the local tools 0.5.14 build to test both Vita routes. Tools 0.5.14 is currently a local test build, not a published app release. The remaining tools 0.5.4 does not provide this Automatic PKG route; tools v0.5.11 was withdrawn. This update does not publish a new tools app.

**Download size: approximately 945 MB.** Rebuilding encrypted package data makes the whole-PKG delta large. Allow about 3 GB free for the ZIP, extracted delta and output when they share a drive, plus system headroom. A downloaded ZIP can also be selected under **Vita → Vita3K PKG → Local patch (optional)**.

**Manual without our tools:** download `Cross-Ange-English-0.1.13-Vita-PKG-xdelta.zip`, verify it using `SHA256SUMS.txt`, and extract its whole-PKG delta. Use [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) or [xdelta3](https://github.com/jmacd/xdelta):

| Your source file | Patch inside the ZIP |
| --- | --- |
| Original Japanese PCSG00597 `.pkg` | `Cross-Ange-English-0.1.13-PKG.xdelta` |

```text
xdelta3 -d -s Original.pkg Cross-Ange-English-0.1.13-PKG.xdelta English.pkg
```

Keep a new output filename. Manual patching also needs no license; Vita3K requires it during installation. Credits and font attribution are already included in the translated package. The standalone CPK/component patches, old per-file PKG profile and separate extras workflow remain retired. Hardware rePatch uses its own verified ZIP/profile to create a complete overlay locally.

Original PKG: **925,548,400 bytes**; SHA-256 `962498429645bf92d0171280b075629ff6dc8100f365ce43805d2cd3e897ebcb`.

English PKG: **944,821,248 bytes**; SHA-256 `59bd8f558f8b657d6a298fa0760b7867f67475c579d531fbfffa9c69143d7c8d`.

`VITA-PKG-XDELTA.json` pins the original, delta and complete output. The ZIP contains that identical profile and one `.xdelta`. `SHA256SUMS.txt`, `VALIDATION.json` and `AUTOMATIC-VALIDATION.json` cover downloads and verification. See [installation instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/patch-installation.md). Existing English PKGs are not supported patch inputs.

**Hardware Vita rePatch:** use the local **Retro Trans 0.5.14** build. In **Vita**, choose **Hardware rePatch**, select the original Japanese PCSG00597 PKG and its matching `work.bin`, and choose a new output folder. Leave **Local patch** blank to download the hardware patch ZIP, or select `Cross-Ange-English-0.1.13-Vita-rePatch-patches.zip`. Click **Create rePatch**, then copy the generated `rePatch/PCSG00597` to `ux0:rePatch/PCSG00597` with VitaShell. Your original game must already be installed and a compatible rePatch plugin enabled. See [hardware instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/repatch-installation.md).

The hardware ZIP is about **5.4 MB**. The tools create the complete translated archive locally; rePatch overlays whole files, so this game needs about **902 MB** for its archive on the Vita. The overlay leaves the original executable, installed game and license unchanged. Physical-Vita gameplay and the manual credits page still need testing. This option does not use the custom Vita3K PKG.

### What changed since v0.1.12

- **Private access:** restored repository and release privacy at the user's request because the whole-PKG download is too large. Earlier anonymous testing remains historical evidence. All ten release assets and game bytes remain unchanged.
- **Hardware Vita:** add a separate hash-verified rePatch ZIP/profile for the local tools 0.5.14 build. PKG extraction for this route uses your matching local license. Physical-Vita testing remains outstanding.
- **Whole-PKG flow:** patch encrypted package bytes directly, without a license, archive extraction or CPK replacement. Download the translation ZIP through Automatic or apply its delta with an external patcher.
- **Retire component flow:** remove component deltas, their manifest, old license-based profile and extras assets. The single translated PKG already includes credits and font attribution.
- **Version and credits:** title footer and manual credits remain **0.1.13**. This distribution update preserves the native-verified game bytes, translation content and original copyright.

Retains the 0.1.12 translations, chapter headings, tutorial graphics, proportional font advances, pixel-width dialogue wrapping and compact briefing/unit/result labels. See the [changelog](https://github.com/retro-trans/Cross-Ange/blob/main/CHANGELOG.md).

### Release status

**Proofreading and full gameplay testing are still needed.** The English output passed isolated native Vita3K installation and all **48 installed file** comparisons. Whole-PKG delta checks reproduce that exact output. The local tools 0.5.12 Windows build passed **260 tests**, with four platform-specific skips, frozen startup and a real complete-PKG patch test without a license argument. `AUTOMATIC-VALIDATION.json` records the fresh published-profile download and Automatic worker checks. Hashes and installation checks do not establish every scene's rendering or gameplay.

Known issues include the duplicate Naomi eye-animation tile, remaining raster regions, original manual prose and movie logos. Some equipment names are provisional and some long dialogue uses 80% sizing. Coverage counts describe identified resources rather than whole-game completion. The custom PKG is for Vita3K; it is not Sony-signed or verified for physical-Vita installation.

Hardware overlay generation passed through the frozen local **tools 0.5.14** app: fresh published downloads, isolated original-PKG extraction with the matching local license, all three output file checks, and unchanged original/license checks. Its suite passed **270 tests**, with four platform-specific skips. `REPATCH-AUTOMATIC-VALIDATION.json` records this proof. Physical-Vita gameplay and system-manual credits remain unverified.

### What's included

English drafts for **17,151 identified structured targets**: scenario dialogue and choices, speaker labels, UI, battle/navigation captions, gallery fields and system titles. Includes all **15 identified chapter/prologue headings** in both graphic variants and **ten identified tutorial pictures**, including their embedded samples. Uses **GenEi LateGo v2 Medium**, native proportional advances and wrapping by pixel width, plus versioned title branding and translation credits on manual page 25.

### How it was translated

The text is **machine-translated** with large language models, then checked and edited against scene context and a researched glossary. English catalogs, terminology and layout records support further review. Human proofreading and gameplay feedback are welcome.
