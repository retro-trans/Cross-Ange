English fan translation of **CROSS ANGE Rondo of Angel and Dragon tr.** for PS Vita (**PCSG00597**, Japanese release).

### Apply

**Install the original game first, then patch its installed files.** You need your own Japanese **PCSG00597 v01.00** PKG and that game's matching `work.bin` (or compatible `.rif`) for installation in Vita3K. Licenses are never included or downloaded. Patching the installed files does not read a license.

The repository and release remain **private**. Download the small CPK delta, optional metadata delta and extras from the [v0.1.13 release](https://github.com/retro-trans/Cross-Ange/releases/tag/v0.1.13) using an account with repository access. The CPK delta is **5,349,702 bytes (about 5.35 MB)**. The whole-PKG ZIP and its profile have been withdrawn.

1. Install the original PKG in Vita3K with its matching license, then close Vita3K and back up your saves and original game files.
2. Locate `<Vita3K data folder>/ux0/app/PCSG00597/cpk/Ange.cpk`. With this computer's configuration it is `E:\Emu\vita3k\fs\ux0\app\PCSG00597\cpk\Ange.cpk`. Other computers may use a different data folder.
3. In **Retro Trans → Apply xdelta**, select that original `Ange.cpk`, `Cross-Ange-English-0.1.13-Ange.xdelta`, and a **new output filename** outside the installed game folder. The existing published tools **0.5.4** supports this manual binary route; local source 0.5.15 removes the withdrawn PKG options. External DeltaPatcher/xdelta3 also work.
4. Verify the output SHA-256 below, then replace the installed `cpk/Ange.cpk` with the patched output, keeping the original backup. Never patch an already translated archive.
5. Optionally patch the original `sce_sys/param.sfo` with `Cross-Ange-English-0.1.13-param.xdelta` to a new file, verify its hash, then replace that installed file. This updates the displayed game title.
6. Extract `Cross-Ange-English-0.1.13-extras.zip` and copy its `sce_sys/manual/025.png` and `sce_sys/font-license.txt` into the installed game's corresponding folders. Read `INSTALL.md`; these extras contain translation credits and required font attribution.
7. Restart Vita3K, launch Cross Ange and check **v0.1.13** in the title footer. Translation credits are on manual page 25.

**Manual commands:**

```text
xdelta3 -d -s Ange.cpk Cross-Ange-English-0.1.13-Ange.xdelta Ange-English.cpk
xdelta3 -d -s param.sfo Cross-Ange-English-0.1.13-param.xdelta param-English.sfo
```

The original archive is **882,846,536 bytes**; the English archive is **902,054,728 bytes**. `BUILD-MANIFEST.json` pins sources, patches and outputs; `SHA256SUMS.txt` covers the downloads. Local file replacement requires enough space for the original backup and patched archive. If your original hash differs, stop and check the game revision or whether a translation/mod is already installed.

Automatic catalog recognition depends on a catalog entry accessible to the app. This private release does not add an entry to the public catalog: use **Apply xdelta** with the downloaded patch. Hardware rePatch remains a separate [small-download route](https://github.com/retro-trans/Cross-Ange/blob/main/docs/repatch-installation.md). Older whole-PKG tools builds 0.5.12–0.5.14 are withdrawn; no new tools release is published by this update.

### What changed since v0.1.12

- Restored the small CPK/component deltas, standard build manifest and credits/font-attribution extras. Install the original game first, then patch its installed archive. CPK patching does not need work.bin; original game installation does.
- Removed the approximately 945 MB whole-PKG ZIP/profile and their current verification downloads. The repository remains private. Historical PKG and public-access verification records remain in source documentation.
- Retained the separate hardware rePatch bundle. Withdrawn local tools 0.5.12–0.5.14 builds are no longer recommended; published tools 0.5.4 supports Apply xdelta. No replacement tools release is published.
- Game files, title branding, credits and translation version remain 0.1.13. This is a distribution change; gameplay and physical-Vita testing remain outstanding.

Retains the 0.1.12 translations, chapter headings, tutorial graphics, proportional font advances, pixel-width dialogue wrapping and compact briefing/unit/result labels. See the [changelog](https://github.com/retro-trans/Cross-Ange/blob/main/CHANGELOG.md).

### Release status

**Proofreading and full gameplay testing are still needed.** The restored component deltas reproduce the exact original English build. Earlier isolated native Vita3K installation verified all 48 installed English file identities; those PKG proofs are retained as historical provenance, not the current installation route. The current local Apply xdelta UI worker has been checked against the full original CPK, with exact output and unchanged original checks. This does not establish every scene's rendering or gameplay.

Known issues include the duplicate Naomi eye-animation tile, remaining raster regions, original manual prose and movie logos. Some equipment names are provisional and some long dialogue uses 80% sizing. Coverage counts describe identified resources rather than whole-game completion. The earlier custom PKG route is withdrawn; current instructions patch the installed original game.

Historical hardware overlay verification used the now-withdrawn local **tools 0.5.14** app: fresh published downloads, isolated original-PKG extraction with the matching local license, all three output file checks, and unchanged original/license checks. Its suite passed **270 tests**, with four platform-specific skips. `REPATCH-AUTOMATIC-VALIDATION.json` records this proof. Physical-Vita gameplay and system-manual credits remain unverified.

The local replacement **tools 0.5.15** passed its **251-test suite**, with four platform-specific skips, and frozen startup with whole-PKG options disabled. CPK output checks and optional metadata/extras checks are recorded in `CPK-VALIDATION.json`. This app remains local; the existing published tools 0.5.4 supports Apply xdelta.

### What's included

English drafts for **17,151 identified structured targets**: scenario dialogue and choices, speaker labels, UI, battle/navigation captions, gallery fields and system titles. Includes all **15 identified chapter/prologue headings** in both graphic variants and **ten identified tutorial pictures**, including their embedded samples. Uses **GenEi LateGo v2 Medium**, native proportional advances and wrapping by pixel width, plus versioned title branding and translation credits on manual page 25.

### How it was translated

The text is **machine-translated** with large language models, then checked and edited against scene context and a researched glossary. English catalogs, terminology and layout records support further review. Human proofreading and gameplay feedback are welcome.
