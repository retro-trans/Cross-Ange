English fan translation of **CROSS ANGE Rondo of Angel and Dragon tr.** for PS Vita (**PCSG00597**).

### Apply — original PKG to translated PKG

Download [Retro Trans 0.5.11 or newer for Windows](https://github.com/retro-trans/retro-trans-tools/releases/latest). The matching translation ZIP downloads through **Automatic**. This game release remains private, so automatic downloads require a GitHub account with access; the app can use your existing GitHub CLI sign-in.

1. Open **Automatic** and browse to your own original Japanese PCSG00597 `.pkg`.
2. Select its matching local NoNpDrm `work.bin` or `.rif` under **Matching license**.
3. Choose a new **Translated PKG** filename and click **Patch**. The app downloads this release's matching translation ZIP automatically.
4. Install the resulting PKG through Vita3K's **File → Install .pkg**, supplying the same matching license. Restart the game and check **v0.1.13** on the title screen. Manual page 25 contains translation credits.

The app uses a generic release profile to identify the game and revision. It handles archive changes internally, rebuilds encrypted PFS and verifies all installed game files in a temporary Vita3K filesystem. You do not need to install the original first or edit a CPK manually. Your source package, license, emulator setup and saves are preserved during conversion. Needs Windows x64, 6 GB free temporary space and the official Vita3K tool download. Licenses are never downloaded or uploaded.

The custom PKG is intended for Vita3K. It is not Sony-signed or verified for physical-Vita installation. [PKG instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/pkg-patching.md) include the standalone CLI alternative.

For a downloaded ZIP override, use **Vita → Vita3K PKG**, select `Cross-Ange-English-0.1.13-Vita-PKG-patches.zip` under **Local patch (optional)** and click **Create translated PKG**.

### Existing component route

The standard `BUILD-MANIFEST.json`, two `.xdelta` patches and extras ZIP remain available for Retro Trans **Automatic**, **Apply xdelta**, Delta Patcher and xdelta3. They use your original decrypted `cpk/Ange.cpk` and `sce_sys/param.sfo`; place outputs and extras using the [installation instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/patch-installation.md). Older app versions can use this route.

### Release status

The published Retro Trans 0.5.11 Windows app downloaded this private translation ZIP automatically and verified all 48 installed files in the rebuilt PKG. Its complete package hash matched the independently verified 0.1.13 build. The Automatic tab worker also passed the same conversion using the source UI. GitHub release checks passed all 247 tests with four platform-specific skips, frozen startup and a real next-launch update. `RETRO-TRANS-0.5.11-VALIDATION.json` records these current checks.


**Early test build: proofreading and full gameplay testing are still needed.** The packaged Retro Trans 0.5.8 app converted the release ZIP and original PKG successfully, verified all 48 installed file hashes in isolated Vita3K, and produced the same complete PKG hash as the independently validated standalone build. The two-component Automatic route also passed both complete-file target checks. Retro Trans's 226-test suite passed with four platform-specific skips; eight package regressions and twenty translation/font/tutorial/branding checks passed. Output installation does not establish that every scene renders correctly.

Existing limitations remain: the duplicate Naomi eye-animation tile, other raster regions, original manual prose and movie logos; provisional equipment names and some native 80% dialogue sizing still need review. Physical-Vita behavior and gameplay of the rebuilt PKG are unverified. Counts describe identified resources, not whole-game completion.

`BUILD-MANIFEST.json` and `VALIDATION.json` retain complete-file delta identities and round trips. `VITA-PKG.json` declares original PKG and per-file identities; `VITA-PKG-SHA256SUMS.txt` covers it and the Vita patch ZIP. Other checksums cover standard patches and the separate extras ZIP. `RETRO-TRANS-VALIDATION.json` records the packaged-app, generic-profile, Automatic and native-installation checks.
