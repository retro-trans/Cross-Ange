First public English translation release of **CROSS ANGE Rondo of Angel and Dragon tr.** for PS Vita (**PCSG00597 v01.00**, Japanese release).

### Apply

**Vita3K — Automatic (local Retro Trans 0.5.16):**

1. Select your original Japanese PKG and its matching **work.bin / compatible NoNpDrm .rif**.
2. Choose a new output PKG and click **Patch**. The tools download about **5.4 MB** of translation patches and rebuild the English PKG locally. Allow **6 GB free**; the Vita3K runtime downloads separately on first use.
3. Install the English PKG in Vita3K with the **same license**, then check **v0.1.13** on the title screen.

The matching license is required for both patching and installation. No game or license is included. **Tools 0.5.16 is currently a local build**; the published tools 0.5.4 supports the manual method below.

**Manual — published Retro Trans Tools or xdelta3:** Install the original game in Vita3K first, close it, and back up its files. Patch `ux0/app/PCSG00597/cpk/Ange.cpk` using `Cross-Ange-English-0.1.13-Ange.xdelta`, then copy the verified output back. Apply the optional `param.sfo` delta and credits/font-license extras. See [full instructions and hashes](https://github.com/retro-trans/Cross-Ange/blob/main/docs/patch-installation.md).

**Hardware Vita:** Use the separate [rePatch instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/repatch-installation.md). Physical-Vita compatibility remains unverified.

### What's included

- English drafts for **17,151 identified text targets**: dialogue, choices, speaker names, UI, battle captions, gallery and system titles.
- **15 chapter/prologue headings** and **10 tutorial pictures**, including embedded samples.
- **GenEi LateGo v2 Medium**, proportional spacing and dialogue wrapping by pixel width.
- Versioned title footer and translation credits on manual page 25.
- Small PKG-rebuild patches, manual CPK/metadata deltas, credits/font attribution and hardware rePatch patches.

### Release status

**Early release: proofreading and full playtesting are needed.** Both Automatic rebuild tests reproduced the verified English PKG and passed all **48 installed-file checks**. File verification does not establish gameplay compatibility.

Known issues: duplicate Naomi eye-animation tile, remaining raster text, original manual prose/movie logos, provisional equipment names and smaller text for some long dialogue. Counts cover identified resources, not whole-game completion.

### How it was translated

Drafted with large language models, then checked and edited using scene context and a researched glossary. Human proofreading and playtesting are welcome.
