English fan translation of **CROSS ANGE Rondo of Angel and Dragon tr.** for PS Vita (**PCSG00597**, Japanese release).

### Apply

**Recommended:** Use [Retro Trans 0.5.11 or newer for Windows](https://github.com/retro-trans/retro-trans-tools/releases/latest). Open **Automatic**, browse to your original Japanese `.pkg`, select its matching local NoNpDrm `work.bin` or `.rif` under **Matching license**, keep **Target** on **Latest**, choose a new **Translated PKG** filename and click **Patch**. The app downloads the compatible translation ZIP and verifies the completed package. Install it through Vita3K's **File → Install .pkg** using the same license, then restart the game and check **v0.1.13** on the title screen.

This release is private. Automatic downloads require a GitHub account with access; Retro Trans can use your existing GitHub CLI sign-in. Use Windows x64, internet access and at least **6 GB free** on the output drive. Your game and license stay local. Conversion runs in an isolated Vita3K filesystem and preserves your existing emulator setup and saves.

For a local ZIP override, download `Cross-Ange-English-0.1.13-Vita-PKG-patches.zip`, open **Vita → Vita3K PKG**, select it under **Local patch (optional)** and click **Create translated PKG**. No original installation or manual archive editing is required.

**Manual patching:** [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher), [xdelta3](https://github.com/jmacd/xdelta) and Retro Trans's **Apply xdelta** accept these component patches:

| Your source file | Patch |
| --- | --- |
| Original decrypted `cpk/Ange.cpk` | `Cross-Ange-English-0.1.13-Ange.xdelta` |
| Original decrypted `sce_sys/param.sfo` | `Cross-Ange-English-0.1.13-param.xdelta` |

```text
xdelta3 -d -s original/Ange.cpk Cross-Ange-English-0.1.13-Ange.xdelta english/Ange.cpk
xdelta3 -d -s original/param.sfo Cross-Ange-English-0.1.13-param.xdelta english/param.sfo
```

Create the `english` folder first, apply both patches and include the release's **extras ZIP** for credits and font attribution. Follow the [installation instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/patch-installation.md) to place the files. The component route requires the exact original decrypted files; these deltas cannot be applied directly to a PKG. Retro Trans can also patch both components together through **Automatic → Folder…**. Existing English builds are not supported upgrade inputs.

Original Japanese PKG: **925,548,400 bytes**; SHA-256 `962498429645bf92d0171280b075629ff6dc8100f365ce43805d2cd3e897ebcb`.

Verified rebuilt English PKG: **944,821,248 bytes**; SHA-256 `59bd8f558f8b657d6a298fa0760b7867f67475c579d531fbfffa9c69143d7c8d`.

`VITA-PKG.json` identifies the supported package and per-file identities. `BUILD-MANIFEST.json` contains component source, output and patch hashes; `VALIDATION.json` records delta round trips. `SHA256SUMS.txt`, `EXTRAS-SHA256SUMS.txt` and `VITA-PKG-SHA256SUMS.txt` cover the corresponding downloads. See [PKG instructions](https://github.com/retro-trans/Cross-Ange/blob/main/docs/pkg-patching.md) for the verified edition and standalone tool.

### Release status

**Proofreading and complete gameplay testing are still needed.** The published Retro Trans 0.5.11 executable downloaded this private translation ZIP and verified all **48 installed files** in an isolated Vita3K installation. The resulting package hash matched the independent build. The Automatic tab worker also passed conversion using the source UI. Release checks passed **247 tests**, with four platform-specific skips, standalone startup and a real packaged update. Installation and hash verification do not confirm every scene's rendering or gameplay.

Known issues include the duplicate Naomi eye-animation tile, remaining raster regions, original manual prose and movie logos. Some equipment names are provisional, and some native dialogue uses 80% sizing. Coverage counts describe identified resources rather than proof that every Japanese element has been translated. The rebuilt PKG is intended for Vita3K; it is not Sony-signed or verified for physical-Vita installation.

Restart the game after installing the patch and confirm the title-screen version. `RETRO-TRANS-0.5.11-VALIDATION.json` records the published-app checks; the original `RETRO-TRANS-VALIDATION.json` retains the earlier 0.5.8 integration results.

### What's included

English drafts for **17,151 identified structured targets**: scenario dialogue and choices, speaker labels, UI, battle/navigation captions, gallery fields and system titles. Includes all **15 identified chapter/prologue headings** in both graphic variants and **ten identified tutorial pictures**, including their embedded samples. Uses **GenEi LateGo v2 Medium**, native proportional advances and dialogue wrapping by pixel width, plus versioned title branding and a translation credits page.

### How it was translated

The text is **machine-translated** with large language models, then checked and edited against scene context and a researched glossary. English catalogs, terminology and layout records support further review. Human proofreading and gameplay feedback are welcome; provisional readings and remaining visual issues still need attention.
